# 纸张对折打孔展开预览

在浏览器里设定一张纸的宽高，按顺序指定若干次**沿当前纸张水平/垂直中线的对折**
（并指定哪一侧折向另一侧），然后在最终折叠面上点击打一个或多个孔。
程序按折叠顺序**逆推**每个孔穿透各层后在原纸上的全部位置，并排实时显示
**折叠面**与**展开图**（原生 SVG），并支持下载展开图 SVG 文件，或把合法
展开结果按 1:1 实际毫米分页到纵向 A4 纸、打包为 **A4 分页定位模板 ZIP**
（含对位十字与打印拼接说明）。

也可以用**反查打孔**：直接在展开图上点击原纸目标孔心，服务端按当前折叠顺序
及折向逐层折回最终折叠面，返回归一化孔心并高亮这一次打孔必然生成的全部
连带孔位，确认后才加入现有打孔点（与在折叠面点击完全等价）。

还可以用**目标孔位排版**：按原纸毫米坐标逐行录入一批目标孔心，服务端把每个
目标折回最终折叠面（多目标可共用同一打孔点）再展开为完整连带孔组，按坐标
容差去重后与目标集合比对——只有连带孔集合与目标集合完全一致、方案打孔点数
不超过上限且通过边界/折痕/保护区校验时才返回可用方案；不可实现时指出缺少的
连带孔或违规目标及原因。页面先预览方案的打孔点与展开结果，确认后以方案整体
替换当前打孔点，仍复用现有展开与下载校验。

还可以划定**原纸保护区**：用毫米坐标录入至多 8 个轴对齐矩形（禁打孔区域），
展开图中以绿色虚线框标出。任一展开孔圆与任一保护区相交或相切即违规，
系统指出原打孔点、触碰的展开孔及保护区，不生成展开图、禁止下载；
反查打孔的待确认结果执行同一判定。

还可以设置可选的**最小纸桥宽度**（毫米，`0` 表示关闭，默认关闭）。启用后
服务端先按现有坐标容差合并展开孔位，再检查任意两个不同孔的圆边净距
（圆心距 − 2r）：净距小于设定宽度即冲突，**相等可以通过**。检查使用空间
网格查找邻近孔对，大批量目标排版时也不会逐对扫描。判定对手动打孔、反查
待确认、目标孔位排版与 SVG 下载四个入口同时生效：反查按「确认加入现有
孔位后的全集」判定，排版按「替换后的方案」判定；冲突时返回首个冲突对的
两孔坐标与实际净距，且不给出可确认方案或可下载 SVG，需修改参数后重新计算。

还可以下载 **A4 分页定位模板**：把合法展开结果按实际毫米 **1:1** 排到纵向
A4 页（210×297mm，四边留白 10mm，可打印区 190×277mm，相邻页重叠 15mm），
按原纸尺寸计算覆盖全纸的分页窗口（窗口从原纸左下角起排，列自左而右、
行自下而上，与原纸坐标方向一致），逐页裁剪纸边、折痕、保护区与孔圆，
跨页图形在相邻页各保留对应片段，全程不缩放。每页标注行列号、原纸窗口
坐标与重叠区对位十字，全部页面连同打印拼接说明（README.txt）打包为
ZIP 下载；分页入口复用孔位/保护区/纸桥校验，违规时拒绝下载。

- 后端：Python + Flask（计算与 SVG 生成均在服务端，结果唯一可复现）
- 前端：原生 HTML / JavaScript / 内联 SVG，无任何前端构建与 CDN 依赖
- 部署：Docker + Compose，一条命令完成依赖安装与启动

## 一条命令启动

需要本机已安装 Docker 与 Docker Compose 插件（Docker Desktop 自带）。

```bash
docker compose up --build
```

首次执行会构建镜像并安装 `requirements.txt` 中的依赖，之后启动 Web 服务。
启动成功后在同一端口访问页面与 API（默认 **8000**）：

- Web 页面：`http://localhost:8000`
- API 根路径：`http://localhost:8000/api/...`（如 `POST http://localhost:8000/api/plan`，
  全部接口见下文「接口」一节）
- 健康检查：`http://localhost:8000/healthz`

后台运行用 `docker compose up --build -d`；停止用
`docker compose down`；查看日志用 `docker compose logs -f`。
端口通过 `HOST_PORT` 更改（见下节），Web 与 API 始终共用同一端口。

## 配置（均为可选）

通过环境变量或项目根目录的 `.env` 文件覆盖，无需修改代码：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `HOST_PORT` | `8000` | 宿主机映射端口（只想换访问端口时改它，例如 `HOST_PORT=9000`） |
| `PORT` | `8000` | 容器内监听端口 |
| `MAX_FOLDS` | `8` | 最多对折次数 |
| `MAX_HOLES` | `24` | 折叠面上最多打孔点数 |
| `MAX_ZONES` | `8` | 原纸上最多保护区个数 |
| `MAX_TARGETS` | `6144` | 单次排版最多目标孔心数（默认 = `MAX_HOLES` × 2^`MAX_FOLDS`） |

例：换到 9000 端口

```bash
HOST_PORT=9000 docker compose up --build
# 访问 http://localhost:9000
```

纸张宽高范围 20–2000 mm，打孔半径 0.5–50 mm（同样可在 `app.py` 顶部调整）。

**最小纸桥宽度** `minBridge` 不是环境变量，而是页面参数（随每次计算提交给
服务端）：在左侧「纸张与打孔器」下输入，单位 mm，留空或填 `0` 表示关闭，
范围 0–2000 mm，步进 0.5 mm。启用后手动打孔、反查待确认、目标排版与 SVG
下载共用同一判定（规则见上文「功能简介」与下文「含糊结果的处理」）。

## 使用说明

1. 输入纸张宽度 W、高度 H 与打孔半径 r（单位 mm），或点 A4 等预设。
   可选填写「最小纸桥宽度」（mm，留空或 `0` 关闭）：展开后任意两个不同孔
   的圆边净距小于该值即判冲突。
2. 用四个按钮依次添加折叠：
   - **垂直对折 · 右折向左**：沿竖直中线，右半翻到左半上（左半不动）
   - **垂直对折 · 左折向右**：左半翻到右半上（右半不动）
   - **水平对折 · 上折向下** / **下折向上**：沿水平中线，含义类似
   每条折法可单独删除，顺序即折叠顺序。
3. 在折叠面（左视图）的**绿色虚线安全框**内单击打孔；单击已有孔可删除；
   修改宽高、半径、折法或孔位后，展开图即时重算。
4. **反查打孔**：点展开图下方的「反查打孔」开关后，在展开图上单击目标孔心。
   服务端把该点按当前折法逐层折回折叠面，返回归一化孔心，并用同一展开算法
   列出本次打孔必然生成的全部孔位：黄色高亮为连带孔位、蓝圈为目标孔，
   折叠面上同步标出反查到的打孔位置。点「确认加入打孔点」后才真正加入
   （之后与手点孔一样参与展开与 SVG 下载）；「取消」或改变纸张、半径、
   折法都会丢弃这次待确认预览。纸桥宽度启用时按**加入现有孔位后的全集**
   判定：本次连带孔之间、连带孔与现有孔之间净距不足都会返回具体原因
   （冲突两孔坐标与实际净距），界面上不出现确认按钮，无法加入。
5. **原纸保护区**：在左侧面板用毫米坐标录入轴对齐矩形（x、y 为矩形左下角，
   原纸坐标系，至多 8 个），「添加保护区」后即绘入展开图（绿色虚线框，
   框内标注「保1」「保2」…序号），每条可单独删除。任一打孔点展开出的
   孔圆与任一保护区**相交或相切**即违规：状态栏指出原打孔点（折叠面坐标）、
   触碰的展开孔坐标及保护区编号，展开图不生成、下载按钮禁用；
   反查打孔的待确认结果同样判定（触碰保护区则返回具体原因、无法确认）。
   保护区必须完整位于原纸内：录入时越界会被拒绝；之后改小纸张尺寸导致
   既有保护区越界时，列表中该项标红并提示「请修正或删除」，修正或删除前
   不生成展开图、不能下载。
6. **目标孔位排版**：在左侧面板的文本框按原纸 mm 坐标逐行录入目标孔心
   （每行「x y」或「x, y」），点「生成排版方案」。可行时折叠面与展开图
   切换为方案预览（预览期间下载按钮禁用），点「确认：替换当前打孔点」后
   方案整体替换现有打孔点，之后与手点孔一样参与展开与 SVG 下载；
   不可实现时状态栏逐条列出首个纸桥冲突对的两孔坐标与实际净距、缺少的
   连带孔坐标、违规目标及原因（触及哪条边界/折痕/保护区）或打孔点超限
   说明，确认按钮不可用。修改纸张、半径、纸桥宽度、折法或保护区会作废
   旧方案预览。
7. 右侧展开图中黑实线为纸张边界，灰虚线为全部折痕，红圆为孔，
   绿色虚线框为保护区；点击「下载展开 SVG」保存 `unfolded.svg`
   （独立文件，含 `mm` 尺寸标注，可直接用浏览器打开或送入激光切割/打印流程）。
8. **A4 分页定位模板**：展开结果合法时「下载 A4 分页模板 (ZIP)」可用，
   按钮下方实时显示分页页数（共 N 页（c 列 × r 行），只依赖纸张尺寸）。
   ZIP 内含每页一个 SVG（`a4_page_r{行}_c{列}.svg`，行自下而上、
   列自左而右）与一份 `README.txt` 打印拼接说明：
   - **打印**：务必按 **100% 比例（实际大小）** 打印，关闭「适应页面」
     「缩放至可打印区域」等选项；打印后可用直尺核对可打印区虚线框为
     190×277mm，否则说明被缩放、拼接会错位。
   - **拼接**：每页页眉标有「第 R 行 第 C 列」与原纸窗口坐标（原点为
     原纸左下角，y 轴向上）。同行相邻页左右重叠 15mm、同列相邻页上下
     重叠 15mm，把重叠区内的蓝色对位十字两两重合（同一原纸坐标）即可；
     建议从第 1 行（最下一行）开始逐行向上、每行自左而右拼接。
   - 孔位、保护区或纸桥净距违规时与展开 SVG 一样拒绝下载（返回 400
     与具体原因）。

### 折叠面视图的线型

- 黑色实线：纸张开口边（对应原纸边界）
- 蓝色虚线：折痕边（当前面在此处与下层相连）

## 含糊结果的处理（重要）

打孔若**压在折痕或纸张边界上**，展开后孔会横跨折痕/边界，产生“一个孔变成
半圆”等有歧义的结果。本应用不允许这种状态：

- 判定规则：孔心到最终折叠面**任意一条边**（无论它当前是开口边还是折痕边）
  的距离必须 **严格大于打孔半径 r**（另加 0.05mm 浮点容差）。
  几何上可证明：历次对折产生的所有折痕，最终都落在折叠面的边界上，
  因此这一条规则同时排除了“压任意历史折痕”与“压原纸边界”两类情况。
- 不满足时：问题孔在折叠面上标为橙色，下方给出具体中文提示
  （碰到的是哪条边、实际距离、需要多大间距），展开图不生成、下载按钮禁用，
  直到孔位被移入安全框。
- 反查打孔同样适用该判定：目标孔心距原纸边界或任一折痕不大于 r 时，
  接口返回具体原因（触及哪条边界/哪条折痕、实际距离），界面上不出现
  确认按钮，无法加入。
- 保护区判定：任一展开孔圆与任一保护区矩形相交**或相切**（圆心到矩形的
  最近距离 ≤ r，另加 0.05mm 容差）即违规，提示中指出原打孔点、触碰的
  展开孔与保护区编号；反查打孔的待确认结果执行同一判定。
- 最小纸桥宽度判定：设置 `minBridge > 0` 后，服务端先按现有坐标容差合并
  展开孔位（重合位置只算一个孔），再检查任意两个**不同**孔的圆边净距
  （圆心距 − 2r）。净距 **小于** 设定宽度即冲突，**相等可以通过**
  （严格 `<` 比较，不含额外容差）；提示给出首个冲突对的两孔原纸坐标与
  实际净距（净距为负时说明两孔圆已重叠）。邻近孔对用空间网格查找
  （格子边长 = 2r + 最小纸桥宽度，只检查相邻九宫格），复杂度近似线性，
  大批量目标排版也不会逐对扫描。
  - 手动打孔与 SVG 下载：按当前全部打孔点展开、合并后的孔位判定，冲突时
    问题打孔点在折叠面标橙，不生成展开图、下载按钮禁用。
  - 反查打孔：按确认加入现有打孔点后的**全集**判定（现有孔一并展开合并），
    冲突时接口返回 400 与具体原因，不返回可确认结果。
  - 目标孔位排版：按方案**替换后**的孔位全集判定，冲突时 `feasible=false`，
    不给出方案 SVG 与可确认的打孔点。
  以上任一入口冲突后，都需要调整孔位（或调小/关闭纸桥宽度、改折法/半径）
  并由服务端重新计算，前端不会基于旧结果放行确认或下载。
- 折叠后纸面小到连打孔器直径都放不下时，同样直接报错提示。
- 重合孔位（例如两个不同的打孔点展开后位置重合）只绘制一次，并在状态栏注明
  合并数量。

## 接口

- `GET /`：页面
- `POST /api/unfold`：入参
  `{width, height, radius, folds: ["vR"|"vL"|"hT"|"hB", ...], points: [{x,y} 归一化], zones: [{x, y, w, h} 原纸 mm], minBridge?: number(mm，0/缺省=关闭)}`，
  返回折叠面几何/SVG、折痕、孔数与展开 SVG；保护区越界、孔圆触碰保护区或
  纸桥净距不足时 `unfoldedSvg` 为 null，`error`/`zoneError`/`bridgeError`
  给出具体原因（`bridgeError` 含冲突两孔 `holeA`/`holeB` 坐标与实际净距
  `clearance`，问题打孔点由 `errorIndex` 给出）
- `POST /api/reverse`：反查打孔。入参
  `{width, height, radius, minBridge?, folds, zones, points?: 现有打孔点（归一化，纸桥判定用）, target: {x, y}（原纸 mm 坐标）}`，
  返回折回最终折叠面的归一化孔心 `center`、本次打孔全部孔位 `holes`；
  目标点触及边界/折痕、保护区越界、连带孔触碰保护区，或加入现有孔位后的
  全集中任意两孔圆边净距小于 `minBridge` 时返回 400 与具体中文原因
- `POST /api/plan`：目标孔位排版。入参
  `{width, height, radius, minBridge?, folds, zones, targets: [{x, y} 原纸 mm]}`，
  返回 `feasible`、折叠面归一化打孔点 `points`、连带孔 `holes` 及方案预览
  SVG；可行时 `points` 可直接替换现有打孔点（再走 `/api/unfold` 校验），
  不可实现时 `missing`（缺少的连带孔）、`violations`（违规目标及原因）与
  `bridgeError`（替换后方案中的首个纸桥冲突对及净距）给出具体信息；
  参数非法（如目标超出数量上限、保护区越界、纸桥宽度越界）返回 400
- `POST /api/download`：同 `/api/unfold` 入参，合法时直接回传 `unfolded.svg` 文件
  （保护区违规或纸桥净距不足时同样拒绝，返回 400）
- `POST /api/download-a4`：同 `/api/unfold` 入参，合法时回传 `a4-pages.zip`
  （每页一个 A4 分页 SVG + `README.txt` 打印拼接说明）。分页参数：纵向 A4、
  四边留白 10mm、可打印区 190×277mm、相邻页重叠 15mm，窗口从原纸左下角
  起排；保护区违规或纸桥净距不足时同样拒绝，返回 400
- `GET /healthz`：健康检查

## 计算原理简述

- 每次对折沿当前面中线，对应尺寸减半；同时维护四条边的身份（开口/折痕）。
- 展开时按折叠顺序逆推，使用物理 mm 坐标：每逆推一层，静止层的点恒等映射，
  翻折层的点关于该层中线镜像，于是一个点每层最多产生两个前像，
  n 次折叠最多得到 2ⁿ 个原纸孔位，再按坐标去重。
- 反查是展开的正向逆映射：目标点每经过一次折叠，静止半不变、翻折半关于
  中线镜像，逐层折回后落在最终折叠面上；再对其做一次展开即得全部连带孔位，
  目标孔必在其中。
- 目标孔位排版：每个目标折回折叠面得到打孔点（多目标可折到同一打孔点，
  按坐标容差去重），再展开为连带孔组；全部连带孔的并集与目标集合作容差
  比对，二者相等且打孔点数不超上限时方案才可行——这保证按方案打孔展开后
  恰好得到目标孔位，不多也不少。
- 所有折痕展开后构成 (2^nv − 1) × (2^nh − 1) 的等分网格，直接绘为灰虚线。
- 保护区为原纸上的轴对齐矩形；孔圆与矩形是否相交/相切用「圆心到矩形的
  最近距离 ≤ 半径」判定（最近距离即圆心到矩形各边的 clamp 距离）。
  判定在去重前的全部展开孔上进行，因此能精确定位是哪一个打孔点的
  哪一个展开孔触碰了哪一个保护区。
- 最小纸桥宽度：展开孔先按坐标容差合并（重合位置只算一个孔），两孔
  圆边净距 = 圆心距 − 2r，净距 < 设定宽度即冲突、相等通过。查找冲突对
  用空间网格：格子边长取 2r + 设定宽度，净距不足的两孔圆心必落在相邻
  九宫格内，与逐对比较结果一致但避免平方级扫描；返回按合并后孔位顺序
  扫描到的首个冲突对（两孔坐标 + 实际净距）。
- A4 分页：可打印区 190×277mm（纵向 A4 四边留白 10mm），相邻页重叠
  15mm，故列步进 175mm、行步进 262mm；列数 = max(1, ⌈(W−190)/175⌉+1)，
  行数同理（H 与 277/262）。窗口 (c, r) 覆盖原纸 x ∈ [175c, 175c+190]、
  y ∈ [262r, 262r+277]（末列/末行可越出原纸，该页只画纸面部分），
  逐页用 clipPath 把纸边、折痕、保护区、孔圆裁到窗口，跨页图形在相邻页
  各保留对应片段，全程 1:1 mm 不缩放。对位十字画在重叠区中线的 1/3、
  2/3 处，相邻页在同一原纸坐标各画一次，打印后重合即可对位。
